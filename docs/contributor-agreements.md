# Contributor agreement acceptance registry

Records who has explicitly accepted the
[MEMBRANE Contributor Rights Agreement](../CONTRIBUTOR_RIGHTS_AGREEMENT.md)
for which pull request, and when. Only entries added through the real
acceptance procedure in that Agreement's own Section 25 belong here — never
a contributor who merely opened a PR.

Only public information is stored here: GitHub handle, PR number, agreement
version, and a link to the contributor's own public acceptance comment. No
legal names, signatures, or other personal data. If a future need arises
for signed legal names (e.g. after incorporating a company or receiving
substantial corporate contributions), migrate to a proper CLA service
instead of extending this table.
