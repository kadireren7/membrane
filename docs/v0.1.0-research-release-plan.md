## Short release notes (draft)

> First public research-release milestone for MEMBRANE: a mixed-precision
> KV-cache runtime, exact sparse retrieval, near-memory/CXL simulation,
> bit-exact CPU quantization, and a synthesizable FPGA datapath, evaluated
> via a unified 128K-context × 512-concurrency discrete-event sweep
> (462/462 scenarios, two open SmolLM2 checkpoints). Includes a
> claim-audited academic manuscript (14 independently-verified citations,
> `paper/main.pdf` built by CI on every push) and a scoped, claim-limited
> outreach package for real FPGA/CXL hardware validation — the single
> largest remaining gap this release discloses honestly rather than
> hides. Five null/negative findings are reported with the same
> visibility as the positive results. No real CXL or FPGA hardware was
> used anywhere in this release; see `README.md`'s Technical Limitations
> and `outreach/hardware-claim-gates.md` for exactly what is and isn't
> claimed.

Also confirm, for the exact tagged commit, that the real GitHub Actions
`CI` and `Paper Build` workflow runs for that commit both show success

the authoritative check, not a substitute for it.

## Rollback conditions

Do not proceed with (or, if already created, un-publish/delete) the
`v0.1.0-research` tag/release if any of the following is found:

- Any verification command above fails, on the exact tagged commit.
- The real GitHub Actions `CI` or `Paper Build` workflow fails for the
  tagged commit.
- A claim-audit or claim-gate violation is found after tagging (e.g. a
  prohibited hardware claim slipped through) — fix it, verify again,
  and re-tag rather than leave an inaccurate tagged release live.
- A reproducibility break is found (a script, path, or command in
  `docs/reproduction.md` or this plan no longer works against the
  tagged commit).

If a rollback condition is hit after a real GitHub Release has already
been published, the correction should be disclosed in `CHANGELOG.md`
and, if severe enough, the release should be marked as a pre-release or
have its notes updated to point at the fix — not silently replaced.
